## 负责人独立浏览器验收

本机随机 loopback 端口运行真实本地 MCP 与临时独立数据文件，不读取生产记录，不发送通知。5 条模拟记录通过原核心计算，网页统计为全部 5、已核实 3、待确认 1、已过期 1，净利润依次为 151、120、61、无、无。桌面实际截图已检查布局。

在真实浏览器的同源 iframe 中分别使用 390、320 CSS 像素视口检查响应式布局：列表与详情均无横向溢出；详情打开时隐藏列表，返回可恢复列表；详情显示 8 项独立条件；320 宽的设置弹窗边界位于视口内。宿主处于后台时，本地验收页仅临时模拟前台可见性以触发真实请求；未修改发布代码的可见性判断。手机验收以实际 DOM 布局和交互结果为依据，不以被浏览器最小窗口宽度裁切的截图作为证据。
